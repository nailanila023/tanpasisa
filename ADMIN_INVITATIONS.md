## Cara mengundang
1. Masuk ke Supabase Dashboard menggunakan akun pemilik project.
2. Buka Authentication > Users.
3. Pilih Invite user.
4. Masukkan satu alamat email pada setiap undangan.
5. Ulangi sampai keenam alamat email di atas diundang.
6. Setelah keenam akun tercatat di Authentication > Users, jalankan `supabase/admins.sql` di SQL Editor untuk memberikan role `admin`.
7. Periksa hasil query verifikasi di bagian akhir SQL.

**Catatan:** daftar dan query sudah disiapkan, tetapi undangan belum dikirim karena proyek Supabase belum tersambung ke sesi ini. Setiap anggota perlu menerima undangan dan mengatur password sendiri.
